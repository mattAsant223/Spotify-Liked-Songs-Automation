# Spotify-Liked-Songs-Automation
Automation for placing your liked songs in a playlist that anyone can see!

This project was heavily inspired by the spotify-youtube automation I had previously done, but more indepth with spotify's api and interacting with both get and post request be it user data or tracks from spotify. 

The main purpose of this application was to make retrieving tracks from your liked songs into a playlist automated which is an much easier process. Why would you want to do this? Main reason is allowing other spotify users to see your liked songs playlist, and to have the rest of the features that come with spotify playlist rather than just downloading tracks, which is the only function of the liked songs collection.

This app is not deployed, so you would have to run this locally, meaning you need to create your own developement app from spotify to grab your client and secret ID. You also need to create a playlist or already have one to paste the playlistID to choose which playlist you want to populate to. The front end visualization was developed with flask.

Hope you enjoy the program and making life using spotify easier!
